# Benchmarks & Inspiration (Priority 5)

## Government / public-sector references (clarity + accessibility gold standard)

Best models for a hybrid public + enterprise platform — sober, accessible, no confusion.

- **[GOV.UK Design System](https://design-system.service.gov.uk/)** + **[Government Design Principles](https://www.gov.uk/guidance/government-design-principles)** — accessible components (forms, errors, navigation), clear user journeys, plain content. The reference for forms and flows.
- **[U.S. Web Design System (USWDS)](https://designsystem.digital.gov/documentation/accessibility/)** — mobile-first, accessible, consistent component library.

## Awwwards "most beautiful" 2025 (vitrine wow-factor)

- **Lando Norris Official** (studio OFF+BRAND) — Site of the Year.
- **Messenger** — WebGL micro-planet, Site of the Year.
- **Bruno Simon Portfolio** — navigable browser 3D world.
- **iCOMAT** — minimalist interface turning a complex technical subject into a coherent visual narrative → model for vulgarizing a technical training offer.

## Inspiration platforms

- **[Awwwards — UI Design](https://www.awwwards.com/websites/ui-design/)** — rated on design, usability, creativity, performance.
- **One Page Love** — scroll storytelling, anchor nav, responsive typography.

## How to use benchmarks

- For **forms / errors / journeys** → copy GOV.UK patterns.
- For **showcase wow** → study Awwwards winners, but keep motion restrained per `motion.md`.
- For **vulgarizing complexity** → iCOMAT-style visual narrative.
