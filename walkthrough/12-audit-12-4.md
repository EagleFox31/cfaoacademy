# 12 — Journal d'audit (story 12-4) · app `audit` (TDD + live)

## Contexte
Gouvernance / sécurité (OWASP A09, RGPD) : tracer **qui fait quoi** sur les actions sensibles,
et permettre une **consultation scopée**. Suite à la remarque « pas de dette » : l'audit ne devait
**pas** être différé silencieusement — c'est une exigence, pas une option.

## Décision d'architecture
**App dédiée `audit`** (pas dans identity) — l'audit est transverse. Modèle **append-only**, jamais
écrit via l'API (recording côté serveur uniquement).

## Tests exécutés (écrits AVANT)
```bash
docker compose exec core pytest -q                       # 46 passed
docker compose exec cerbos /cerbos compile --tests ...   # 33 OK (+ AuditLogSuite)
# live : moa crée une affectation → trace lisible via /audit
```
Cas : `record_audit` crée l'événement ; liste anonyme refusée ; liste **scopée** (allowed→visible,
denied→vide) ; **lecture seule** (POST → 403, pas d'écriture API) ; **intégration** (créer une
affectation laisse une trace). Cerbos `audit_log` : admin in-scope ALLOW, **hors-scope DENY**, **learner DENY**.

## Modifications
- App `audit/` : `AuditEvent` (acteur, action, ressource, `org_path`, métadonnées), `record_audit()`,
  `AuditViewSet` (read-only, liste scopée par query plan sur `org_path`), policy `audit_log`.
- `identity/views.py` : `record_audit()` sur **création** et **suppression** d'affectation
  (actions sensibles = octroi/révocation d'accès).
- Wiring : `INSTALLED_APPS += audit`, route `/api/v1/core/audit/`, migration `audit 0001`.

## Résultat final
- **pytest 46** · **Cerbos 33** · **live OK** : `POST assignment` → 201, `/audit` (moa) renvoie
  l'événement `assignment.create` avec le **vrai `sub`** de l'acteur, **scopé** au périmètre.

## Périmètre couvert
- Journal append-only, **non écrivable par l'API**, **lecture scopée** (multi-scope via query plan).
- Traçabilité des **octrois/révocations de rôles** (le plus sensible).

## NON couvert (suite, explicite)
- Étendre le recording aux mutations **org_unit / user** (même `record_audit`, à brancher).
- Rétention / export du journal ; corrélation avec l'audit **Cerbos** (décisions d'autorisation).
